# FitSync — Find Your Perfect Fit

FitSync is a responsive SaaS landing page concept designed to help users find their ideal clothing sizes across different fashion brands using a personalized measurement profile.

The goal is to simplify online clothing shopping by reducing size confusion between brands.

## 🌐 Live Demo

https://fitsync-tau.vercel.app/

## ✨ Features

- **Modern Landing Page:** Clean and premium SaaS-inspired interface.
- **Responsive Design:** Optimized for desktop, tablet and mobile devices.
- **Personalized Fit Concept:** Helps users discover suitable clothing sizes across brands.
- **Interactive Navigation:** Smooth navigation between website sections.
- **Mobile Navigation:** Responsive hamburger menu.
- **Interactive Demo:** Demonstrates the personalized fit experience.
- **Contact Form:** Includes input validation and a success message.
- **Scroll Animations:** Smooth reveal effects for website sections.

## 🛠️ Technologies Used

- HTML5 — Website structure and semantic elements.
- CSS3 — Styling, responsive layouts and animations.
- JavaScript — Interactive functionality and form validation.
- Google Fonts — DM Sans and Manrope.
- Git and GitHub — Version control and source code management.
- Vercel — Website deployment.

## 🚀 Run Locally

1. Clone the repository:

```bash
git clone https://github.com/Charan-online/fitsync.git
```

2. Open the project folder:

```bash
cd fitsync
```

3. Open `index.html` in your browser.

You can also use the Live Server extension in Visual Studio Code.
